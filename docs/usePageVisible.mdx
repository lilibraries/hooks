Detect whether the page is visible. The `visibilitychange` event doesn't fire when restoring from the bfcache, so this hook also listens to the `pageshow` event to re-detect.

## API

```ts
function usePageVisible(): boolean;
```

Results:

- Returns `true` if the page is visible, otherwise `false`.

## Example

```tsx
import React from "react";
import { usePageVisible } from "@lilib/hooks";

function Example() {
  const visible = usePageVisible();
  ...
}
```
