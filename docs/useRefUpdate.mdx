This hook is similar to [`useUpdate`](./useUpdate), but it is built on [`useRefEffect`](./useRefEffect) internally, so ReactRefs in the dependency array are dereferenced to `ref.current` before comparison. It is useful when the ref target itself is an update dependency.

Note: plain objects with a `current` property are treated as ReactRefs and dereferenced, so they cannot be used as dependency values directly.

## API

```ts
function useRefUpdate(effect: React.EffectCallback, deps?: React.DependencyList): void;
```

Params:

- **`effect`:** The effect to run after an update. It may return a cleanup function.
- **`deps`:** The dependency array. Its elements can be plain values or ReactRefs.

## Example

```tsx
import { useRef } from "react";
import { useRefUpdate } from "@lilib/hooks";

function Example() {
  const domRef = useRef<HTMLDivElement>(null);

  useRefUpdate(() => {
    // `domRef.current` is the DOM node.
  }, [domRef]);

  return <div ref={domRef}>...</div>;
}
```
