This hook is similar to [`useLayoutUpdate`](./useLayoutUpdate), but it is built on [`useLayoutRefEffect`](./useLayoutRefEffect) internally, so ReactRefs in the dependency array are dereferenced to `ref.current` before comparison. It runs synchronously before the browser paints (layout phase).

Note: plain objects with a `current` property are treated as ReactRefs and dereferenced, so they cannot be used as dependency values directly.

## API

```ts
function useLayoutRefUpdate(effect: React.EffectCallback, deps?: React.DependencyList): void;
```

Params:

- **`effect`:** The effect to run after an update. It may return a cleanup function.
- **`deps`:** The dependency array. Its elements can be plain values or ReactRefs.

## Example

```tsx
import React, { useRef } from "react";
import { useLayoutRefUpdate } from "@lilib/hooks";

function Example() {
  const domRef = useRef<HTMLDivElement>(null);

  useLayoutRefUpdate(() => {
    // `domRef.current` is the DOM node.
  }, [domRef]);

  return <div ref={domRef}>...</div>;
}
```
