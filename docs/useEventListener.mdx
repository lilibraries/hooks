Set up an event listener on the target.

## API

```ts
function useEventListener<T extends EventTarget = EventTarget, E extends Event = Event>(
  target: T | React.RefObject<T | null>,
  eventName: string,
  listener: (event: E) => void,
  options?: boolean | { capture?: boolean; once?: boolean; passive?: boolean },
): void;
```

Params:

- **`target`:** Event target. It can be `undefined`, `null`, an event target, or a ref object that references an event target.
- **`eventName`:** Event name.
- **`listener`:** Listener function.
- **`options`:** Similar to the third parameter of the [`addEventListener`](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener) function.
