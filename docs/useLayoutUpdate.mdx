It's similar to [`useUpdate`](./useUpdate), but it runs synchronously before the browser paints. It uses [`useIsomorphicLayoutEffect`](./useIsomorphicLayoutEffect) internally.

## API

```ts
function useLayoutUpdate(effect: React.EffectCallback, deps?: React.DependencyList): void;
```

## Example

```tsx
import { useState } from "react";
import { useLayoutUpdate } from "@lilib/hooks";

function Example() {
  const [signal, setSignal] = useState({});

  useLayoutUpdate(() => {
    console.log("Signal changed");
  }, [signal]);

  return <button onClick={() => setSignal({})}>Change signal</button>;
}
```
