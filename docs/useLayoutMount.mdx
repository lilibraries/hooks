It's similar to [`useMount`](./useMount), but it runs synchronously before the browser paints. It uses [`useIsomorphicLayoutEffect`](./useIsomorphicLayoutEffect) internally.

## API

```ts
function useLayoutMount(effect: React.EffectCallback): void;
```

Parameters:

- **`effect`:** The effect to run after the component mounts. It may return a cleanup function.

## Notes

- Runs before the browser paints; avoid heavy computation to not delay rendering.
- During SSR it falls back to `useEffect` via `useIsomorphicLayoutEffect`.
