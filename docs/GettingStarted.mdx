`@lilib/hooks` is a collection of practical React hooks covering async data, states, effects, callbacks, refs and browser APIs — written in TypeScript, compatible with React 16.8+, 17, 18 and 19, and safe for SSR and StrictMode.

## Features

- More than 50 hooks covering async data, effects, states, callbacks, refs and browser APIs.
- Works with React 16.8+, 17, 18 and 19.
- SSR and StrictMode safe — graceful fallbacks outside the browser, and idempotent effects with proper cleanup.
- Fully typed — written in TypeScript.
- Ships ESM, CJS and UMD builds.
- Tree-shakeable — bundlers can drop unused hooks from the ESM build.

## Quick start

```tsx
import { useLoad } from "@lilib/hooks";

function UserProfile({ userId }: { userId: string }) {
  const { data, error, loading } = useLoad(
    () => fetch(`/users/${userId}`).then((response) => response.json()),
    [userId],
  );

  if (loading) {
    return <div>Loading...</div>;
  }

  if (error) {
    return <div>Something went wrong.</div>;
  }

  return <div>Hello, {data.name}!</div>;
}
```

For the full API reference and live examples, check out the docs of each hook listed below.

## Hooks

### Async

| Hook                       | Description                                                |
| -------------------------- | ---------------------------------------------------------- |
| [`useLoad`](./useLoad)     | Load async data, typically for network requests.           |
| [`useReload`](./useReload) | Reload all `useLoad` requests that share the same `key`.   |
| [`useSubmit`](./useSubmit) | Submit network requests such as create, update and delete. |

### Effects

| Hook                                                       | Description                                                                                            |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [`useMount`](./useMount)                                   | Run an effect after the component is mounted.                                                          |
| [`useUpdate`](./useUpdate)                                 | Run an effect after the component updates (the initial mount is skipped).                              |
| [`useUnmount`](./useUnmount)                               | Run an effect when the component unmounts.                                                             |
| [`useRefEffect`](./useRefEffect)                           | Like `React.useEffect`, but ReactRefs in the deps are dereferenced to `ref.current` before comparison. |
| [`useRefUpdate`](./useRefUpdate)                           | Like `useUpdate`, but ReactRefs in the deps are dereferenced to `ref.current` before comparison.       |
| [`useLayoutMount`](./useLayoutMount)                       | Like `useMount`, but runs before the browser paints.                                                   |
| [`useLayoutUpdate`](./useLayoutUpdate)                     | Like `useUpdate`, but runs before the browser paints.                                                  |
| [`useLayoutRefEffect`](./useLayoutRefEffect)               | Like `useRefEffect`, but runs before the browser paints.                                               |
| [`useLayoutRefUpdate`](./useLayoutRefUpdate)               | Like `useRefUpdate`, but runs before the browser paints.                                               |
| [`useIsomorphicLayoutEffect`](./useIsomorphicLayoutEffect) | `React.useLayoutEffect` in the DOM, `React.useEffect` during SSR.                                      |

### States

| Hook                                       | Description                                                                                                     |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| [`useCache`](./useCache)                   | Cache data for a certain period of time, with optional sync between components sharing the same cache instance. |
| [`useToggle`](./useToggle)                 | Manage a boolean value.                                                                                         |
| [`useSetState`](./useSetState)             | Like `this.setState` of class components, merging partial state updates.                                        |
| [`useSafeState`](./useSafeState)           | Like `React.useState`, but setting state after unmount is safe.                                                 |
| [`useDelayedValue`](./useDelayedValue)     | Delay updates to a value.                                                                                       |
| [`useMemoizedValue`](./useMemoizedValue)   | Return the previous value until the value actually changes (deep comparison).                                   |
| [`useThrottledValue`](./useThrottledValue) | Throttle a value.                                                                                               |
| [`useDebouncedValue`](./useDebouncedValue) | Debounce a value.                                                                                               |

### Callbacks

| Hook                           | Description                                                            |
| ------------------------------ | ---------------------------------------------------------------------- |
| [`useRaf`](./useRaf)           | Invoke a callback before the browser repaints.                         |
| [`useIdle`](./useIdle)         | Invoke a callback when the browser is idle.                            |
| [`useAnimate`](./useAnimate)   | Run JavaScript animations.                                             |
| [`useTimeout`](./useTimeout)   | Execute a callback after a delay.                                      |
| [`useInterval`](./useInterval) | Run a callback repeatedly at a fixed interval.                         |
| [`usePersist`](./usePersist)   | Keep a stable function identity while always calling the latest logic. |
| [`useRerender`](./useRerender) | Re-render the component manually, usually for mutable data.            |
| [`useThrottle`](./useThrottle) | Use a throttled callback.                                              |
| [`useDebounce`](./useDebounce) | Use a debounced callback.                                              |

### Refs

| Hook                                   | Description                                                                                    |
| -------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [`useLatestRef`](./useLatestRef)       | A ref that always points to the latest value, avoiding stale closures in long-lived callbacks. |
| [`usePreviousRef`](./usePreviousRef)   | A ref that points to the value from the previous update.                                       |
| [`useComposedRef`](./useComposedRef)   | Compose multiple refs (objects or callbacks) into one.                                         |
| [`useMountedRef`](./useMountedRef)     | A ref that tells whether the component is mounted.                                             |
| [`useUnmountedRef`](./useUnmountedRef) | A ref that tells whether the component is unmounted.                                           |

### Browser

| Hook                                                   | Description                                                                        |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| [`useTitle`](./useTitle)                               | Set the document title.                                                            |
| [`useFavicon`](./useFavicon)                           | Set the document favicon.                                                          |
| [`useOnline`](./useOnline)                             | Detect whether the network is online.                                              |
| [`useDarkMode`](./useDarkMode)                         | Detect whether the system prefers a dark color scheme.                             |
| [`usePageVisible`](./usePageVisible)                   | Detect whether the page is visible, including bfcache restores.                    |
| [`useWindowFocus`](./useWindowFocus)                   | Detect whether the window has focus.                                               |
| [`useMatchMedia`](./useMatchMedia)                     | Determine whether the document matches a media query.                              |
| [`useWindowSize`](./useWindowSize)                     | Get the window size.                                                               |
| [`useElementSize`](./useElementSize)                   | Get the size of a DOM element.                                                     |
| [`useIntersecting`](./useIntersecting)                 | Detect whether an element intersects the viewport or a specified root.             |
| [`useClickOutside`](./useClickOutside)                 | Trigger a callback when clicking outside the target area.                          |
| [`useEventListener`](./useEventListener)               | Set up an event listener on the target.                                            |
| [`useResizeObserver`](./useResizeObserver)             | Observe an element's size changes.                                                 |
| [`useIntersectionObserver`](./useIntersectionObserver) | Observe changes in an element's intersection with another element or the viewport. |
| [`useCookie`](./useCookie)                             | Get, set and/or remove cookies.                                                    |
| [`useLocalStorage`](./useLocalStorage)                 | Get, set and/or remove `localStorage`.                                             |
| [`useSessionStorage`](./useSessionStorage)             | Get, set and/or remove `sessionStorage`.                                           |
