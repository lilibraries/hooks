Return a ref object whose `.current` property always points to the latest value. It is typically used to read the latest value inside long-lived callbacks (timers, event listeners) to avoid stale closures.

## API

```ts
function useLatestRef<T>(value: T): React.MutableRefObject<T>;
```

## Example

```ts
import React from "react";
import { useLatestRef } from "@lilib/hooks";

function Example(props) {
  const valueRef = useLatestRef(props.value)
  ...
}
```
