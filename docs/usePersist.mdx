Return the same function identity regardless of how the `callback` argument changes. The returned function behaves exactly like `callback`.

## API

```ts
function usePersist<T extends (...args: any[]) => any>(callback: T): (...args: Parameters<T>) => ReturnType<T>;
```

## Example

```tsx
import { usePersist } from "@lilib/hooks";

function Example() {
  const callback = usePersist(() => {
    // Do something.
  });
  ...
}
```
