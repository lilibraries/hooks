Load async data, typically for network requests. The `callback` function must return a promise. Loads automatically after mount by default (and again when `deps` change); set the `imperative` option to `true` to trigger loading manually via `load` instead.

## API

```ts
type PromiseResolve<T extends Promise<any>> = T extends Promise<infer P> ? P : never;
type LoadCallback = (...args: any[]) => Promise<any>;
type LoadData<T extends LoadCallback> = PromiseResolve<ReturnType<T>>;

function useLoad<Callback extends LoadCallback>(
  callback: Callback,
  deps?: React.DependencyList,
  options?: {
    key?: {};

    idle?: boolean | IdleRequestOptions;
    imperative?: boolean;
    independent?: boolean;

    fallback?: Callback;
    initialData?: LoadData<Callback>;
    defaultParams?: Parameters<Callback>;

    retry?: boolean | ((error: any) => boolean);
    retryLimit?: number;
    retryInterval?: number | ((count: number) => number);
    fallbackRetry?: boolean | ((error: any) => boolean);
    fallbackRetryLimit?: number;
    fallbackRetryInterval?: number | ((count: number) => number);

    polling?: boolean;
    pollingInterval?: number;
    pollingInPageHidden?: boolean;
    pollingIntervalInPageHidden?: number;

    autoReloadWaitTime?: number;
    autoReloadOnPageShow?: boolean;
    autoReloadOnWindowFocus?: boolean;
    autoReloadOnNetworkReconnect?: boolean;

    onSuccess?: (data: LoadData<Callback>) => void;
    onFailure?: (error: any) => void;
    onFinally?: () => void;
  },
): {
  data: LoadData<Callback> | undefined;
  error: any;
  loading: boolean;
  reloading: boolean;
  initializing: boolean;

  load: (...params: Parameters<Callback>) => ReturnType<Callback>;
  reload: () => void;
  cancel: () => void;

  update: (newData: LoadData<Callback> | ((prevData?: LoadData<Callback>) => LoadData<Callback>)) => void;
};
```

Params:

- **`callback`:** A function that returns a promise. It is automatically called after the component is mounted by default.
- **`deps`:** Auto reload dependency list. Default is an empty array. It doesn't work when the `imperative` option is `true`.
- **`options`:** Options object.
  - **`options.key`:** A shared key that can be any data type except `null` and `undefined`, and must be immutable. By default, if multiple requests for the same key appear on the page, only the first one will be sent, and the others will get the data by listening to internal events. You can prevent the default behavior by setting the `independent` option to `true`. Another use of the `key` option is reloading all associated requests together with the [`useReload`](./useReload) hook.
  - **`options.idle`:** Run the callback during the browser's idle periods. You can pass an `IdleRequestOptions` object to limit the max waiting time.
  - **`options.imperative`:** Run the callback manually by calling the `load` function, rather than automatically after the component is mounted.
  - **`options.independent`:** Set this option to `true`, even if the `key` are the same, request callbacks in the page are independent and all of them will be executed.
  - **`options.fallback`:** When the `callback` function rejects an error and the count of retries has been exhausted, the `fallback` function will be called. Usually used for an alternate data source.
  - **`options.initialData`:** Initial data. Used when no request has resolved yet.
  - **`options.defaultParams`:** The default parameter array set for `callback` and `fallback`. Used by the first load, or by `reload` when no params have been passed via `load(...params)` yet.
  - **`options.retry`:** Enable retrying the callback. Default is `false`. It can be a function that receives the error and returns whether to retry.
  - **`options.retryLimit`:** Callback retry limit. Default is `3`.
  - **`options.retryInterval`:** Callback retry interval, in milliseconds. Defaults to exponential growth: the `count`-th retry waits 2^(count-1) × 1000 ms. You can set a function that returns a number value for this option, for example `(count) => Math.pow(2, count)`.
  - **`options.fallbackRetry`:** Enable retrying the fallback function after it fails too. Default is `false`. It can be a function that receives the error and returns whether to retry.
  - **`options.fallbackRetryLimit`:** Fallback retry limit. Default is `3`.
  - **`options.fallbackRetryInterval`:** Fallback retry interval, in milliseconds. Defaults to exponential growth like `retryInterval`. It can also be a function.
  - **`options.polling`:** Enable polling when the page is visible. Default is `false`.
  - **`options.pollingInterval`:** Polling interval when the page is visible, in milliseconds. Default is `30000`.
  - **`options.pollingInPageHidden`:** Enable polling when the page is hidden. Default is `false`. This option is not associated with the `polling` option.
  - **`options.pollingIntervalInPageHidden`:** Polling interval when the page is hidden, in milliseconds. Default is `60000`.
  - **`options.autoReloadWaitTime`:** Throttle wait time on auto reload, in milliseconds. Default is `10000`.
  - **`options.autoReloadOnPageShow`:** Enable auto reload on page show. Default is `false`.
  - **`options.autoReloadOnWindowFocus`:** Enable auto reload on window focus. Default is `false`.
  - **`options.autoReloadOnNetworkReconnect`:** Enable auto reload on network reconnect. Default is `false`.
  - **`options.onSuccess`:** Success event.
  - **`options.onFailure`:** Failure event.
  - **`options.onFinally`:** Finally event.

Results:

- **`data`:** Resolved data. Initial value is `undefined` when the `initialData` is not specified.
- **`error`:** Rejected error. Initial value is `null`.
- **`loading`:** Loading state. Initial value is opposite to the `imperative` option.
- **`reloading`:** Equal to `loading && data !== undefined`. Provided for convenience.
- **`initializing`:** Equal to `loading && data === undefined`. Provided for convenience.
- **`load`:** Load function. Used in the same way as the `callback`. It returns a promise that resolves with the data on success, or rejects with the error on failure. Note: calling it before the component mounts returns a promise that never settles, so do not call it during `useLayoutEffect`.
- **`reload`:** Reload function. It cancels the in-flight request (including retries, polling, etc.) first, then reloads with the params from the most recent `load` call (or `defaultParams` if none were ever passed).
- **`cancel`:** Cancel everything, including the executing request, polling, automatic loading, etc. The promise returned by the cancelled `load` stays pending forever.
- **`update`:** Update the `data` locally without sending a request.
